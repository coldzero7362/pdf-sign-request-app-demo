# 색상 (USIGN 팔레트)

출처: dev.usign.kr 핵심 색상. 정의는 `frontend/src/app/globals.css`의 `:root`에 있습니다.
팔레트 원색은 `--c-*`에 두고, 화면 코드는 역할 이름(`--bg`, `--text`, `--accent` …)만 씁니다.

| 그룹 | 이름 | 값 | 쓰는 곳 |
|---|---|---|---|
| Brand | Primary | `#1560FD` | 주 버튼, 진행 중 배지, 1번 수신자 |
| | Link | `#4468F9` | 링크 |
| | Header | `#345BF8` | 상단 바 배경 (흰 글자), 메일 머리글 |
| | Navy | `#181A29` | 배치 안내 말풍선, 대화상자 뒤 배경, 그림자 |
| Text | Text | `#111111` | 본문 |
| | Heading | `#242940` | 제목, 칸 이름 |
| | Sub | `#555555` | 보조 문구 (`.muted`) |
| | Muted | `#808087` | 페이지 번호처럼 덜 중요한 글자 (`--faint`) |
| Surface | Page BG | `#F2F5F8` | 페이지 배경 |
| | Surface | `#FFFFFF` | 카드, 패널 |
| | Border | `#E2E7EA` | 테두리, 표 구분선 |
| Status | Success | `#2FC673` | 작성한 칸, 완료 배지 배경 |
| | Warning | `#FFA019` | 작성할 칸(수신자 화면), 만료 배지 배경 |

## 접근성 (흰 배경 대비, WCAG AA 기준 4.5:1)

| 색 | 대비 | 처리 |
|---|---|---|
| Primary, Link, Header | 5.09, 4.57, 5.25 | 글자·버튼에 그대로 사용 |
| Muted `#808087` | 3.92 | 작은 보조 문구에는 Sub(`#555555`, 7.46)를 쓰고, Muted는 덜 중요한 곳에만 |
| Success `#2FC673` | 2.22 | 면·테두리에만. 글자는 `#178049`(4.98) |
| Warning `#FFA019` | 2.04 | 면·테두리에만. 글자는 `#A86400`(4.68) |

## 팔레트에 없어 임시로 정한 색

| 용도 | 값 | 비고 |
|---|---|---|
| 오류, 거절, 취소, 삭제 | `#D32F2F` | 흰 배경 대비 4.98 |
| 수신자 5·6번째 구분색 | `#808087`, `#0B7285` | 1~4번은 Primary, Warning, Success, Navy |

- 다크 모드는 팔레트가 밝은 테마 기준이라 두지 않았습니다 (`color-scheme: light`).
